# NEXUS ONE v2.0 — RENDER SHOT LIST (materials/premium-finishes pass)

For the later render pass (media tools). This agent does NOT generate images —
spec only. Design language and no-gos below are binding on whoever renders.

## Global design language (Hari-approved, per poster render v2)

- Glossy black device finish (premium, fingerprint-honest, not matte grey).
- Cyan light strips: thin luminous accent lines along the spine rails and the
  leading bar edge — the same cyan signature as the poster render.
- "NEXUS" engraving on the spine back shell, subtle, legible at hero angle.
- Dark background, studio-product lighting, soft rim light; device is the hero.
- Reference image (look, not geometry):
  `~/workspace/nexus-one/poster_render/media-generation-nexus-one-poster-style-v2-0-5215237f-4046-4c92-bfa0-187889192dff.webp`
- v2 materials to READ visually in both shots: titanium rails (brushed-metal
  rails/dovetail glint), carbon-fibre weave texture on the spine back shell,
  ceramic-glass accent strips (glassy highlight), polymer end caps (satin black,
  visually distinct from the metal — RF windows, never metallic).

## Hard no-gos (render is rejected if any appear)

1. No segmented / telescoping / multi-piece expanding phone — the device is ONE
   continuous rollable panel on ONE drum; it unrolls, it does not telescope.
2. No free-floating hologram globe / volumetric hologram effects — holography is
   a v2.0 research track, not a depicted feature.
3. No fantasy parts — every depicted part must exist in the v1.0 BOM or this
   study (drum, rails, leading bar, end caps, spine shell, module rail, kickstand,
   keyboard module); no invented ports, screens, or mechanisms.

  ends. Cyan light strip running the spine length.
- **Angle:** three-quarter hero — camera ~30° above the surface plane, ~35° off

  engraving read.
- **Materials read:** CFRP weave on spine shell, Ti rails glinting at the edges,
  satin-black polymer end caps, ceramic accent strips catching one highlight.
- **Background:** dark studio void, soft top-left key, cyan rim echo.

## Shot (b) — Laptop mode

- **Geometry to depict:** phone open (panel unrolled, leading bar extended, same
  162.9 mm roll axis as the stick), keyboard module docked to the module rail
  (B01 dovetail, 120 × 24 recess) on the spine back, kickstand deployed at
  **~70°** from the surface plane holding the open panel upright like a laptop
  lid. Screen content: Nexus OS desktop-mode UI (abstract dark UI with cyan
  accents — no fake app screenshots, no readable fake text).
- **Angle:** three-quarter front view, slightly above keyboard height, so the
  docked keyboard, the ~70° kickstand triangle, and the upright panel read as one
  connected system. Show the dovetail engagement (keyboard seated IN the rail,
  not floating near it).
- **Materials read:** same v2 stack as shot (a); keyboard module in matching
  glossy black with cyan backlight hint.
- **Background:** dark studio void, consistent lighting with shot (a) so the two
  shots read as one set.
- **No-gos specific to this shot:** keyboard must be docked (no floating
  keyboard), kickstand must show a real hinge/foot contact (no levitating
  panel), no second screen or hologram above the keyboard.
